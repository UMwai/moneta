# ADR 0004 — Authentication

**Status:** accepted

## Options

1. **Hand-rolled local auth: argon2id password hashing (@node-rs/argon2) + signed
   HttpOnly session cookie (jose HS256), first-run setup wizard** — minimal deps,
   fully offline.
2. better-auth / Auth.js — featureful (OAuth, magic links) but heavy for a self-hosted
   single-household app and drags in config most users never touch.
3. No auth (bind to localhost) — simplest, but people will inevitably expose it on a
   LAN/VPS; unacceptable for financial data.

## Decision

**Option 1.** Small enough to audit, no external identity dependency. Scope: session
fixation-safe cookie rotation on login, constant-time compare, rate-limited login route.
OAuth/passkeys can be added later if the project grows.
